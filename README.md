# GNU/Linux & USB HID devices

This repository contains files to explore the HID subsystem on GNU/Linux. Therefore, the following is provided:

- pico_fw: Firmware for a Raspberry Pi Pico to act as a simple HID device
- userspace_app: Userspace application to access the Pico HID device over the hidraw API
- hid_tusb_driver: Linux driver for the Pico HID device
